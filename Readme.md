# MasterBackEndWithOAUTH

Backend API built with Express and MongoDB to demonstrate secure authentication and authorization using JSON Web Tokens (JWT) and OAuth-based flows.

## Features

- User registration and login with hashed passwords using bcrypt.
- JWT-based authentication for protected routes.
- Input validation using express-validator.
- CORS-enabled API for frontend integration.
- MongoDB persistence using Mongoose.
- Structured project with environment-based configuration.

## Tech Stack

- Node.js
- Express
- MongoDB & Mongoose
- JSON Web Token (JWT)
- bcryptjs
- express-validator
- dotenv
- cors

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm or yarn
- MongoDB instance (local or cloud, e.g. MongoDB Atlas)
